## VFiles 2.9.2（2026-11-12）

目录历史修复版本。运行时 API 和数据库结构与 2.9.1 兼容，没有新增迁移。

### 修复内容

- **目录版本总数为 0**：版本详情面板请求目录历史时没有真正把 `with_total=true`
  发给后端，根目录和 `/aka/foobar` 等子目录都显示 0 个版本。现在服务层会显式发送
  该参数，并重新加载切换路径后的总数。
- **第一次后退没有变化**：处于“当前版本”时，加载历史会把当前快照写入浏览版本，
  第一次后退又选中当前快照。现在加载只高亮当前版本，第一次后退直接进入上一个版本。
- **前进回当前版本**：前进到当前版本时退出历史模式，状态标签恢复“当前版本”。
- 增加嵌套子目录历史测试和前端查询参数测试。

### 升级说明

- 无数据库迁移；从 2.9.0/2.9.1 升级无需额外操作。
- 目录历史仍然返回“该路径存在过的快照”；只有 `with_total=true` 才返回总数。
- 若浏览器仍显示旧数据，强刷页面以加载新的前端 bundle。
