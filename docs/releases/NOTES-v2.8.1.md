## VFiles 2.8.1

安全修复版本，重点处理账号接管、范围越权、同源存储型 XSS 与凭据轮换问题。

### 安全修复

- **访问令牌边界**：访问令牌不能再修改账号邮箱、密码或创建/删除登录凭据；这些账号操作只接受浏览器会话（Cookie）。令牌泄露后无法再通过新增登录密码实现持久化接管。
- **凭据轮换**：修改主密码、管理员重置密码和管理员强制下线现在会同时撤销该账号的全部会话与访问令牌，旧令牌在改密后立即失效。
- **管理员边界**：系统信息与全量审计日志仅限 `admin`；`manager` 仍可管理普通用户，但不能查看 admin/manager 的详情或会话。
- **受限范围**：修复受限密码通过收藏 add/remove 响应读取授权目录之外路径的问题。
- **WebDAV/S3 XSS**：WebDAV 与 S3 的 GET 响应强制 `Content-Disposition: attachment` 并加 sandbox CSP；WebDAV 补齐 CSP、`nosniff`、`X-Frame-Options` 等安全头。用户上传的 HTML/SVG 不再能在应用源里执行脚本。
- **路径与日志**：文件和路径拒绝控制字符、NUL、U+2028/U+2029，避免日志/审计/终端注入。
- **账号枚举**：禁用账号登录与密码错误返回同一响应。
- **分享码**：新分享码由 8 位提高到 16 位（约 74 位有效熵）；历史 8 位链接继续可查询和停止。
- **开放注册**：启用 `VFILES_AUTH_ALLOW_REGISTER` 时按来源 IP 限流。
- **审计**：管理员重置密码、删除用户现在写入审计日志。

### 行为变化

- `/api/auth/profile`、`/api/auth/password`、`/api/auth/credentials*` 不再接受 `Authorization: Bearer`，只接受 Cookie 会话。
- 改密、管理员重置或强制下线会撤销全部访问令牌；依赖长期令牌的脚本需要重新创建令牌。
- WebDAV/S3 在浏览器中打开文件会下载而不是内联预览；WebDAV/S3 同步客户端不受影响。
- `manager` 访问 `/api/admin/system-info`、`/api/audit/*` 会返回 `403`。
- 含控制字符或 Unicode 行分隔符的路径/文件名不再接受新建；历史数据如存在此类名称需要先重命名。

### 升级说明

- 本版本**没有新增数据库迁移**。
- 分享码格式变化向后兼容：旧 8 位分享链接仍有效。
- 公开部署仍建议关闭开放注册，并按 [部署文档](../DEPLOYMENT.md) 配置 HTTPS；WebDAV 使用 HTTP Basic，公网必须只经 HTTPS 暴露。
