# VFiles 用户手册

本手册面向日常使用者，介绍当前 Web 界面里最常见的操作路径。

## 首次使用

1. 由管理员启动服务并完成初始化。
2. 使用管理员创建的账号登录系统。
3. 进入文件浏览器后，从当前目录开始浏览、上传和管理文件。

如果你负责首次部署，请先看 [QUICK_START.md](QUICK_START.md) 和 [ADMIN_SETUP.md](ADMIN_SETUP.md)。

## 文件浏览

### 目录导航

- 点击目录名称进入子目录。
- 使用面包屑或 `..` 返回上一级。
- 顶部会显示当前所在路径。

### 代码与文档预览

- 代码文件按扩展名高亮显示，Markdown 中的围栏代码块同样会着色。
- 代码/文本预览底部有「复制」按钮，可一键复制文件原文（按钮会显示「已复制」）。

### 目录树

宽屏桌面左侧会显示目录树：点击目录即可跳转，展开箭头按需加载子目录，当前目录会高亮
并自动展开其上级；也可以把文件或文件夹拖到目录树上完成移动。

### 查看详细信息

- 桌面端选中条目后，右侧「详细信息」面板会显示类型、大小、修改与创建时间；
- 也可以右键（移动端长按）条目，选择「详细信息」打开弹窗，其中带有预览、下载、
  分享的快捷入口。

### 排序

- 工具栏的排序控件显示当前字段与方向，点击可切换字段或升降序，「文件夹置顶」也在其中；
- 桌面端还可以直接点击列表表头切换排序字段与方向；
- 该入口在列表、网格与移动端都可用。

### 文件列表

列表中会显示：

- 名称
- 修改时间
- 类型
- 大小

目录项和快捷项会以可交互链接显示，点击即可进入。

### 外观（浅色 / 深色）

- 顶部导航栏的「跟随系统 / 浅色 / 深色」按钮用于切换配色，选择会保存在浏览器本地，
  下次打开自动生效。
- 选择「跟随系统」时不写入偏好，页面跟随操作系统的深色模式实时变化。
- 深色模式覆盖文件列表、网格、预览、移动/分享等对话框与版本历史页面。

## 上传文件

### 拖拽上传

把桌面上的文件或文件夹直接拖到浏览器窗口内，页面会显示「松开即可上传」浮层并注明
目标目录，松手后文件会加入上传队列并打开上传对话框，可继续补充备注后上传。

### 普通上传

1. 点击“上传文件”。
2. 选择一个或多个文件。
3. 等待上传完成，列表会自动刷新。

### 大文件上传

系统支持分块上传。网络中断后重新发起上传时，客户端会优先复用已完成的分块。

## 目录操作

你可以在界面中完成：

- 创建目录
- 重命名目录
- 移动目录
- 删除目录

创建多级目录时，系统会自动补齐缺失的父目录。

## 文件操作

对文件可进行：

- 预览
- 下载
- 重命名
- 移动
- 删除
- 查看历史

文本和部分常见文件类型支持在线预览；不支持预览的文件可直接下载。

## 历史与快照

### 文件历史

在文件详情或历史入口中，可以查看：

- 每次版本变更时间
- 变更类型
- 版本对应的消息
- 文本 diff（适用于可比对内容）

### 快照

快照用于记录某个时间点的目录状态，适合做目录级回放或恢复参考。

## 搜索

支持两类搜索：

- 文件名 / 路径搜索
- 内容搜索（取决于服务端是否启用）

常见过滤方式包括：

- 当前目录范围
- 文件 / 目录类型
- 分页加载

## 分享

如果服务端启用了分享功能，可以为文件或目录创建分享链接。

当前分享配置重点是：

- 目标路径
- 过期时间

分享创建后，可在列表中查看、访问或禁用该分享码。

## 管理员常用操作

管理员可通过界面或 CLI：

- 查看用户列表
- 创建用户
- 修改角色或禁用状态
- 重置密码
- 撤销用户现有会话

## 常见问题

### 上传失败

- 检查文件体积是否超出当前实例限制
- 检查浏览器网络连接
- 重试上传并观察是否从已完成分块继续

### 无法登录

- 确认用户名/邮箱与密码正确
- 检查账号是否被禁用
- 检查服务端是否启用了认证

### 页面能打开但接口异常

- 先访问 `/api/health`
- 让管理员检查服务日志和数据库状态
