# VFiles 用户手册

本手册面向日常使用者，介绍当前 Web 界面里最常见的操作路径。

## 首次使用

1. 由管理员启动服务并完成初始化。
2. 使用管理员创建的账号登录系统。
3. 进入文件浏览器后，从当前目录开始浏览、上传和管理文件。

如果你负责首次部署，请先看 [QUICK_START.md](QUICK_START.md) 和 [ADMIN_SETUP.md](ADMIN_SETUP.md)。

## 文件浏览

### 目录导航

- 点击目录名称进入子目录。
- 使用面包屑或 `..` 返回上一级。
- 顶部会显示当前所在路径。

### 代码与文档预览

- 代码文件按扩展名高亮显示，Markdown 中的围栏代码块同样会着色。
- 代码/文本预览底部有「复制」按钮，可一键复制文件原文（按钮会显示「已复制」）。

## 登录与账号

登录页与找回 / 重置密码页共用同一套「品牌 + 卡片」外壳，右上角可切换主题：

- **登录方式**用分段控件切换：登录 / 邮箱验证码 / 注册（管理员关闭注册时不显示「注册」）；
- 输入框带前置图标（用户名、邮箱、密码、验证码），错误与提示以行内提示条呈现；
- 「邮箱验证码」模式：填邮箱 → 发送验证码 → 输入 6 位验证码登录；
- 「登录」模式右下角提供「忘记密码？」入口；找回密码页填写绑定邮箱发送重置链接，
  重置页支持从邮件链接自动带入 token（也支持手动粘贴）；
- 服务端未启用认证（`ENABLE_AUTH=false`）或关闭注册时，页面顶部给出来源说明。

### 多选：详情面板会变成选择摘要

勾选多个条目后（悬停行首复选框，或用 <kbd>Ctrl</kbd>/<kbd>Shift</kbd> 多选），
右侧面板不再显示单条详情，而是：

- **选择摘要**：已选数量 + 大小合计（含目录数量）；
- **条目列表**：前 5 个名称 + 「还有 N 项」；
- **批量操作**：下载全部 / 移动 / 全选（当前视图）/ 清空选择 / 删除全部，
  与列表上方的批量操作条完全一致；
- 只选中一条时仍显示该条目的详细信息。

> 悬停行首出现的复选框会正确反映选中状态（此前点选后看起来「没勾上」）。

### 存储用量

侧栏下半部分展示工作区概览（数据来自 `GET /api/files/overview` 的服务端聚合）：

- **存储用量**：总量 + 「N 文件 · M 目录」；
- **分类占比条**：按文档 / 图片 / 视频 / 音频 / 其它分组，用颜色分段展示构成，
  下方图例给出每类的占用大小（悬停可见文件数）；分类极小（不足 2%）时仍保留最小宽度，
  避免在总占用很大时消失；空工作区显示灰色空轨道；
- **收藏 / 最近更新**：收藏的条目可直接打开，最近更新的文件（最多 8 个）点击即可定位；
- 上传、删除、移动等操作完成后侧栏会自动刷新。

### 目录树

宽屏桌面左侧会显示目录树：点击目录即可跳转，展开箭头按需加载子目录，当前目录会高亮
并自动展开其上级；也可以把文件或文件夹拖到目录树上完成移动。

### 查看详细信息

右侧「详细信息」面板（桌面端）按主流网盘的信息面板组织：

- **预览区**：图片显示缩略图，其它类型显示类型图标；切换条目会即时更新；
- **名称与路径**，右上角「×」可直接收起面板（收起后列表恢复显示「操作」列）；
- **详细信息**：类型 / 大小 / 位置（所在目录）/ 修改时间 / 创建时间 / 最近提交；
- **操作**：主操作「预览」（文件夹为「打开」）用主色按钮突出，其余为下载 / 分享 / 历史版本 /
  重命名 / 移动，删除单独用红色；
- 面板与「批量操作条」一样**吸顶**：列表很长、向下滚动时面板不会滚出视野，
  操作始终可用；内容过长时面板内部滚动。

移动端与右键菜单里的「详细信息」弹窗共用同一份内容（弹窗自带标题栏关闭按钮）。


### 移动端搜索结果

- 搜索框、结果摘要与**筛选 chips 吸附在顶部**（滚动结果时始终可达，符合主流移动端行为）；
- 类型 chips 在窄屏为**单行横向滚动**（不换行、不挤压列表），点击即筛选，再点「全部」恢复；
- 结果行显示名称高亮、所在目录与「大小 · 时间」，长按可打开操作菜单。

### 移动端底部操作栏

- 底部栏为**图标 + 文字**（更多 / 上一级 / 首页 / 新建 / 上传 / 刷新），触屏上无需猜测图标含义，
  每个按钮高度 44px、等分屏宽，不会互相挤压；「上传」用主色突出；
- 「更多」可切换操作模式：**导航 / 历史 / 批量**（历史模式提供目录的前进/后退/最新，
  批量模式显示已选数量与批量操作）；
- 提示条（成功/失败）显示在底部栏上方，不会遮挡面包屑、搜索结果或列表内容；
- 列表行里的元信息为弱化文本「大小 · 时间」，与桌面保持一致。

### 滚动与常驻区域（桌面端）

桌面端采用与主流网盘一致的**应用外壳**：整页不再滚动，只有文件列表在自己的区域内滚动。

- 工具栏、列表列头、状态栏（当前目录/选择项数/快捷键提示）始终可见；
- 侧栏与右侧「详细信息」面板固定，不随列表滚动；
- 列表滚到底部会自动继续加载下一页；列头显示排序字段与方向（小箭头图标）；
- 移动端仍是整页滚动 + 底部操作栏，不受此布局影响。

### 键盘快捷键

按 <kbd>?</kbd>（或在底部状态栏点「全部快捷键（?）」）打开快捷键面板，分组列出：

| 分组 | 快捷键 | 作用 |
| --- | --- | --- |
| 导航 | <kbd>↑</kbd> <kbd>↓</kbd> <kbd>←</kbd> <kbd>→</kbd> | 移动高亮行（网格中 ↑↓ 按整行移动） |
| 导航 | <kbd>Home</kbd> <kbd>End</kbd> / <kbd>Enter</kbd> / <kbd>Esc</kbd> | 跳到首尾、打开或预览、退出选择态 |
| 选择 | <kbd>Ctrl</kbd>+<kbd>A</kbd> | 全选当前视图（⌘+A 同效） |
| 选择 | <kbd>Ctrl</kbd>+单击 / <kbd>Shift</kbd>+单击 / <kbd>Shift</kbd>+<kbd>↑↓</kbd> | 加选、连续选择、键盘扩展选择 |
| 操作 | <kbd>F2</kbd> / <kbd>Delete</kbd> / <kbd>Shift</kbd>+<kbd>F10</kbd> | 重命名、删除、打开行菜单 |
| 预览 | <kbd>←</kbd> <kbd>→</kbd> / <kbd>+</kbd> <kbd>-</kbd> <kbd>0</kbd> <kbd>R</kbd> | 切换文件、缩放复位旋转 |

在输入框里输入时不会触发列表快捷键；所有弹窗都支持 <kbd>Esc</kbd> 关闭。

### 调整列表列宽（桌面端）

- 把鼠标移到表头两列之间的**细线**上，光标变成左右箭头即可**拖动**改变列宽
  （名称 / 修改时间 / 类型 / 大小四列都可调）；
- **双击**手柄恢复该列默认宽度；聚焦手柄后可用 <kbd>←</kbd> <kbd>→</kbd> 每次微调 16px，
  <kbd>Home</kbd> 恢复默认；
- 列宽会**记住**（与视图模式、排序等偏好一起保存在本地），下次打开仍生效；
- 悬停表头会高亮该列，提示可以排序/调整。

### 视图与排序菜单

- 「视图」菜单只负责**显示方式**（列表/网格）与网格缩略图大小；
- 「排序」菜单负责**排序字段**（名称/修改时间/大小/类型）、**升降序**与**文件夹置顶**——
  文件夹置顶在主流网盘里属于排序选项，因此只在这里出现，不再与视图菜单重复。

### 预览

双击（或右键「预览」）文件即可打开预览弹窗，图片、PDF、视频、音频、Markdown、代码与纯文本都在同一套灯箱里：

- **顶部工具条**：左侧是文件图标、名称与大小；右侧是 **所在文件夹**、**下载**、
  **全屏**；代码/文本还会出现 **复制内容**（复制后按钮变「已复制」）；
- **切换**：预览区左右两侧悬浮「上一张 / 下一张」箭头，底部显示「当前 / 总数」；
  键盘 <kbd>←</kbd> <kbd>→</kbd> 同样可切换；
- **图片缩放**：滚轮缩放、底部控件（缩小 / 适应窗口 / 放大 / 左旋），
  键盘 <kbd>+</kbd> <kbd>-</kbd> 缩放、<kbd>0</kbd> 复位适应、<kbd>R</kbd> 旋转；
  放大后可拖动平移，底部实时显示缩放百分比；
- **打开所在文件夹**：关闭预览并跳转到该文件所在目录，同时高亮该行；
- 不支持预览的类型会给出「暂不支持在线预览」与「下载文件」按钮；
- <kbd>Esc</kbd> 关闭预览。



列表区的「空」与「失败」使用同一套结构（插画 + 标题 + 说明 + 操作），与主流网盘一致：

- **空文件夹**：提示「此文件夹为空」，并给出「上传文件」「新建文件夹」两个主操作；
- **搜索无结果**：文件名搜索时提示换个关键字；**内容搜索**时额外给出「改为文件名搜索」的一键切换
  （内容搜索只匹配文件内容，名称命中的文件不会出现），并可「清空搜索」；
- **加载失败**：红色插画 + 服务端返回的具体原因（例如「服务器内部错误」）+「重试」按钮；
- **未选择条目**（右侧详情面板）：紧凑版空状态，提示选中后显示详细信息。

## 排序

- 工具栏的排序控件显示当前字段与方向，点击可切换字段或升降序，「文件夹置顶」也在其中；
- 桌面端还可以直接点击列表表头切换排序字段与方向；
- 该入口在列表、网格与移动端都可用。

### 文件列表的操作入口

列表里的每一项都有三种操作入口，按场景选最顺手的即可（与主流网盘一致）：

- **行内「⋯」菜单**：鼠标移到某一行，名称右侧出现「⋯」，点开即是该条目的完整操作
  （预览 / 历史版本 / 详细信息 / 收藏 / 重命名 / 移动 / 下载 / 分享 / 删除；目录则是
  打开 / 在此新建子目录 / …）。**关闭了「操作」列、开着详情面板时同样可用**，不需要先选中再跑到面板里点。
- **行内复选框**：鼠标移到行上会出现复选框，直接勾选即进入选择态——顶部会出现批量操作条
  （已选数量 / 全选当前视图 / 清空选择 / 下载 / 移动 / 重命名 / 删除），**不需要先点工具栏的「批量选择」**。
  勾选多项时「重命名」自动禁用；`Esc` 或「清空选择」退出。
- **操作列**（可在「视图」菜单里开关）：关闭详情面板时，每行直接显示一排图标按钮。
  开启详情面板后关闭该列，避免与面板里的操作重复。

辅助入口：

- 右键任意行：打开同一套菜单（在行位置弹出）。
- 键盘：`Shift+F10` 或菜单键打开当前行菜单；`↑`/`↓` 移动当前行，`Shift`+方向键区间选择，
  `Ctrl/⌘+A` 全选，`F2` 重命名，`Delete` 删除，`Enter` 打开/预览，`Esc` 逐层退出。
- 选择工具条**吸顶**：文件很多、列表滚到很下面时也始终停在顶部，随时可以下载/移动/删除。

### 文件列表

列表中会显示：

- 名称
- 修改时间
- 类型
- 大小

目录项和快捷项会以可交互链接显示，点击即可进入。

### 外观（浅色 / 深色）

- 顶部导航栏的「跟随系统 / 浅色 / 深色」按钮用于切换配色，选择会保存在浏览器本地，
  下次打开自动生效。
- 选择「跟随系统」时不写入偏好，页面跟随操作系统的深色模式实时变化。
- 深色模式覆盖文件列表、网格、预览、移动/分享等对话框与版本历史页面。

## 上传文件

### 拖拽上传

把桌面上的文件或文件夹直接拖到浏览器窗口内，页面会显示「松开即可上传」浮层并注明
目标目录，松手后文件会加入上传队列并打开上传对话框，可继续补充备注后上传。

### 搜索结果筛选与定位

搜索完成后，列表上方会出现结果工具条：

- 左侧是结果摘要（如「找到 3 项 · 文档 2 项」）；结果较多时提示已显示数量；
- 右侧是**类型筛选**：全部 / 文件夹 / 文档 / 图片 / 视频 / 音频 / 其它，
  每个 chip 带数量，只显示有结果的类型；点击即可切换，再点「全部」取消筛选；
- 每条结果在名称下方标出**所在目录**（如 `/项目/2026`），便于区分同名文件；
  列表与网格视图都会显示；
- 新一轮搜索或清空搜索会重置筛选。

### 上传队列

在上传对话框里选中文件后，会看到队列面板：

- 顶部是概览：「待上传 N 项」以及各类状态计数（排队 / 上传中 / 完成 / 失败 / 取消），
  上传中会额外显示**整体进度条**；
- 右侧的批量操作按需出现：**重试失败项**、**清除已完成**、**全部取消**；
- 每个文件是一行紧凑条目：类型图标、文件名（目录上传会显示相对目录）、大小与状态；
  排队时可以填写「版本备注」（写进版本历史），上传中显示单文件进度条；
- 失败的行会给出服务端返回的原因，并提供**重试**（立即重新入队上传）与从列表移除；
- 上传中可随时取消单个文件或全部；全部成功后队列自动清空并刷新列表，
  有失败项时保留队列并弹出提示。

### 工具栏上传菜单

工具栏右侧的「上传」是**分裂按钮**：

- 点主按钮：打开上传对话框并直接弹出**文件选择器**；
- 点右侧小箭头：展开菜单，可选择 **上传文件 / 上传文件夹 / 新建文件夹**；
  「上传文件夹」会在打开对话框的同时直接弹出**目录选择器**（浏览器支持按目录批量选择，
  保留相对路径），适合一次导入整个文件夹；
- 工具条上仍保留独立的「新建文件夹」按钮，常用操作不需要展开菜单。



1. 点击“上传文件”。
2. 选择一个或多个文件。
3. 等待上传完成，列表会自动刷新。

### 大文件上传

系统支持分块上传。网络中断后重新发起上传时，客户端会优先复用已完成的分块。

### FTP 批量导入

如果要一次导入成百上千个文件，用 FTP 客户端比在浏览器里逐个选择更快。该功能在默认配置下
就是开启的；上传对话框里的「用 FTP 批量导入」卡片会给出当前部署的连接地址、端口、账号、
加密状态与被动端口段，管理员也可以直接看文档或调用 `/api/files/ftp-info`。
如果管理员在服务器上执行 `VFILES_FTP_ENABLED=false`，则该卡片不会出现。

- **地址从哪来**：卡片里的「服务器」会标注地址来源（管理员指定 / 当前访问地址 /
  站点地址 / 服务绑定地址 / 本机网卡地址）。服务端总是优先给出**客户端连得上**的地址；
  若只剩回环地址可用，卡片会提示「仅本机可访问」，此时远程客户端需要改用服务器 IP 或域名。
- **连接方式**：FileZilla / WinSCP / `lftp` / `curl` / Python `ftplib` 等都能用。
  以 `curl` 为例（把文件传到当前目录）：

  ```
  curl -T 本地文件.txt ftp://用户名@服务器:2121/目录/
  curl --ftp-create-dirs -T 本地文件.txt ftp://用户名@服务器:2121/新建目录/文件.txt
  ```

  如启用了 FTPS，加上 `--ftp-ssl`（FileZilla 选择「要求显式 FTP over TLS」）。
- **路径就是你的文件树**：登录后 `/` 是根目录，目录结构与网页端完全一致；
  `..` 到根目录为止，看不到别人的文件。
- **同名文件生成新版本**：重复上传同一路径会新增一个版本，并出现在该文件的「历史版本」里；
- **历史版本**：列表上方会说明保留策略（历史长期保留，可随时预览 / 对比 / 下载 / 恢复；
  删除文件会一并删除其历史）；右侧详情面板可用于**版本预览**与**版本对比**，
  加载失败时给出「加载历史记录失败 + 重试」，没有历史时提示「暂无历史记录」；
  内容相同的文件不会重复占用空间。
- **历史粒度**：管理员可配置为一个会话一次快照（默认）、每个文件一次快照，或者不产生快照。
  默认策略下，历史里会出现类似「FTP 导入（200 个文件）」的条目。
- **不支持**：追加上传（`APPE`）与断点续传上传（`REST`）会被明确拒绝，请重新上传完整文件；
  下载支持断点续传。
- **网络要求**：客户端必须使用被动模式，且防火墙要放行服务端配置的被动端口段。
- **服务器本地导入**：如果数据本来就在服务器上（例如旧系统迁移），管理员可以执行
  `vfiles import <目录> --target <目标目录>` 直接导入，不走网络；重复执行会跳过未变化的文件。

## 目录操作

你可以在界面中完成：

- 创建目录
- 重命名目录
- 移动目录
- 删除目录

创建多级目录时，系统会自动补齐缺失的父目录。

### 移动文件或目录

「移动」对话框按主流网盘的选择器组织：

- 顶部一行摘要显示待移动的条目（多选时显示前三个 + 「共 N 项」）；
- 目标目录用**面包屑**呈现（根目录 / 图片 / 2026…），每个层级都可点击；左侧「↑」返回上一级；
- 下方是当前目录的子文件夹列表，点击进入下一层；待移动的目录及其子目录会置灰并标注「待移动目录」；
- 底部确认按钮会带上目标名（例如「移动到「文档」」）；若当前目录不可作为目标，
  会在列表下方给出一行原因（例如「报告.txt 已经在当前目录」）并禁用确认按钮；
- 当前层没有子文件夹时显示「此处没有子文件夹」，仍可直接确认移动到这一层。



对文件可进行：

- 预览
- 下载
- 重命名
- 移动
- 删除
- 查看历史

文本和部分常见文件类型支持在线预览；不支持预览的文件可直接下载。

## 历史与快照

### 文件历史

在文件详情或历史入口中，可以查看：

- 版本列表：当前版本高亮并标注「当前版本」，其余按「第 N 版」编号，显示变更类型、
  更新消息、相对时间、作者与短哈希；
- 每个版本的操作：**预览**（在右侧面板查看该版本内容）、**对比**（与该版本的父版本做
  文本 diff）、**下载**、**恢复**（当前版本不提供恢复，避免无意义的新版本）；
- 宽屏下为左右两栏（左侧版本列表、右侧预览/对比结果），窄屏下详情面板自动排到列表
  上方，并提供「收起详情」；
- 变更类型与更新消息的对应关系：上传、创建、删除、重命名、恢复、备注等。

### 快照

快照用于记录某个时间点的目录状态，适合做目录级回放或恢复参考。

## 搜索

支持两类搜索：

- 文件名 / 路径搜索
- 内容搜索（取决于服务端是否启用）

常见过滤方式包括：

- 当前目录范围
- 文件 / 目录类型
- 分页加载

## 分享

如果服务端启用了分享功能，可以为文件或目录创建分享链接。对话框分两步：

1. **填写**：顶部显示被分享的条目（图标 + 名称 + 路径），下面选择**链接有效期**
   （1 小时 / 1 天 / 7 天 / 30 天 / 1 年 / 永久，默认 7 天），点「生成链接」；
   选择「永久」时不会发送过期时间，链接不会自动失效（提示语也会相应变化）；
2. **结果**：展示只读的分享链接与「有效期至 …」（永久链接显示「永久有效」），并提供三个操作——
   **复制**（就地反馈「已复制」，同时提示可直接发送给对方）、**打开链接**（新标签页）、
   **停止分享**（删除该链接并回到填写态）。

关闭对话框会重置状态，下次打开不会残留上一次的链接。

### 分享链接筛选与批量清理

「我的分享」页面上方提供状态筛选（带数量）：

- **全部 / 有效 / 已过期 / 已被访问**——点击即过滤，再点「全部」恢复；筛选无结果时给出对应空状态与「查看全部」；
- 存在已过期链接时，页头出现**「清理过期链接（N）」**按钮：二次确认后逐个停止并显示进度
  （`清理中 2/5`），完成后从列表移除并提示「已清理 N 个过期链接」；失败会提示剩余数量。



管理员在顶栏账号菜单进入「审计日志」，用于事后追溯：

- **记录内容**：登录成功 / 失败、上传、下载、删除、移动、创建/停止分享、
  分享下载、用户创建与更新、强制下线；
- **每条包含**：时间、用户（匿名操作记为「匿名」）、动作（中文标签）、对象路径或分享码、
  结果（成功 / 失败）、**来源 IP** 与**设备类型**（由 User-Agent 解析，如「Windows · Chrome」
  「iPhone · Safari」，悬停可看原始 UA）、以及失败原因等说明；
- **筛选**：按用户名 / IP 搜索、按动作与结果过滤；**分页**每页 50 条；
- **时间范围**：全部时间 / 今天 / 近 7 天 / 近 30 天，或选「自定义…」后填写开始与结束日期
  （结束日期按包含当天处理，本地时区计算）；范围会显示在副标题上；
- **导出**：页头的「导出 CSV」按当前筛选条件（含时间范围）导出附件（最多 1 万条，带 BOM 可直接用 Excel 打开）；
  导出本身也会记入审计（`audit.export`），便于追溯「谁在什么时候导出了哪些记录」；
- **只读**：页面顶部明确说明「不能修改或删除」；接口不提供修改/删除入口
  （`DELETE`/`PUT` 返回 405），数据库层也用触发器禁止 `UPDATE`/`DELETE`，
  因此审计记录不可篡改，即使管理员也无法删除。



在顶栏账号菜单里进入「我的分享」，集中管理自己创建的分享链接：

- 列表按创建时间倒序，每行显示条目图标与名称、所在路径、**有效期状态**（长期有效 /
  有效期至 … / 已过期）、**访问次数**与最近访问时间，以及完整链接；
- 每行提供 **复制**（就地反馈「已复制」）、**打开**（新标签页）与 **停止**（二次确认后立即失效）；
- 链接较多时可「刷新」重新拉取；没有链接时给出「还没有分享链接」的空状态与「去选择文件」入口；
- 该页面同样只在服务端启用分享功能时可用（未启用时会给出提示）。

## 用户管理（管理员）

管理员在顶栏账号菜单里进入「用户管理」，页面与文件浏览器使用同一套视觉：

- **页头**：用户总数（筛选时显示「当前显示 N 位」）、**搜索**（用户名 / 邮箱 / 角色中文名）与刷新；
- **角色筛选 chips**：全部 / 管理员 / 管理者 / 普通用户，带人数，只显示实际存在的角色；
- **列表**：头像 + 用户名（自己的账号标注「当前账号」）、邮箱、角色下拉、状态圆点、创建时间（相对时间，悬停看完整值）；
- **邮箱改为按需编辑**：默认展示文本，鼠标悬停该行时出现铅笔图标，点击后行内出现输入框与
  「保存 / 取消」（Enter 保存、Esc 取消），不再整列都是输入框；
- **操作**：禁用 / 启用、强制下线（带二次确认，不能对自己操作）；
- 加载中显示骨架行；加载失败给出「加载失败 + 重试」；没有用户或筛选无结果时给出对应的空状态与「清除筛选」。

## 管理员常用操作

管理员可通过界面或 CLI：

- 查看用户列表
- 创建用户
- 修改角色或禁用状态
- 重置密码
- 撤销用户现有会话

## 常见问题

### 上传失败

- 检查文件体积是否超出当前实例限制
- 检查浏览器网络连接
- 重试上传并观察是否从已完成分块继续

### 无法登录

- 确认用户名/邮箱与密码正确
- 检查账号是否被禁用
- 检查服务端是否启用了认证

### 页面能打开但接口异常

- 先访问 `/api/health`
- 让管理员检查服务日志和数据库状态
